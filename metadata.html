Metadata

Information about the page, placed in the head.

<meta>

Definition

Gives information about the page to browsers and search engines.

Attributes

AttributeRole
charsetCharacter encoding, use UTF-8
nameKind of info: description, viewport, author
contentValue of that info
http-equivActs like an HTTP header, e.g. refresh

Example (code)

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<meta name="description" content="HTML review">

<title>

Definition

Text shown in the browser tab.

Attributes

AttributeRole
(none)Only global attributes

Example (code)

<title>HTML Review</title>

<link>

Definition

Connects the page to an external resource, mostly CSS.

Attributes

AttributeRole
relRelation, e.g. stylesheet or icon
hrefPath to the file
typeFile type, e.g. text/css

Example (code)

<link rel="stylesheet" href="css/style.css">
