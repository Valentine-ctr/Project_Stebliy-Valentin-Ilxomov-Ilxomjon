Links & images

Connect pages and show pictures.

<a>

Definition

Creates a hyperlink to another page, file or website.

Attributes

AttributeRole
hrefDestination address (URL or file)
target_blank opens the link in a new tab
relRelation; use noopener with _blank
titleTooltip on hover

Example (code)

<a href="index.html">Go home</a>
<a href="https://www.w3.org" target="_blank" rel="noopener">W3C</a>

Example (result)

Go home W3C

<img>

Definition

Displays an image. It is an empty tag.

Attributes

AttributeRole
srcPath to the image file
altText shown if the image fails; read by screen readers
widthWidth in pixels
heightHeight in pixels

Example (code)

<img src="images/logo.svg" alt="HTML logo" width="100">
