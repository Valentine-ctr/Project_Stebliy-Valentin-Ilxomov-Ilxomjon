Lists

Organise items in order or without order.

<ul / li>

Definition

ul = unordered list (bullets). li = one list item.

Attributes

AttributeRole
classCSS class for styling
idUnique identifier

Example (code)

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Example (result)

  • HTML
  • CSS
  • JavaScript

<ol>

Definition

Ordered list (numbers). Use when the order matters.

Attributes

AttributeRole
typeNumbering style: 1, A, a, I, i
startFirst number of the list
reversedCounts backwards

Example (code)

<ol type="A" start="3">
  <li>Write code</li>
  <li>Test it</li>
  <li>Publish</li>
</ol>

Example (result)

  1. Write code
  2. Test it
  3. Publish

<dl / dt / dd>

Definition

Description list: dt = term, dd = its description.

Attributes

AttributeRole
(none)Only global attributes

Example (code)

<dl>
  <dt>HTML</dt>
  <dd>Structure of the page</dd>
  <dt>CSS</dt>
  <dd>Style of the page</dd>
</dl>

Example (result)

HTML
Structure of the page
CSS
Style of the page
