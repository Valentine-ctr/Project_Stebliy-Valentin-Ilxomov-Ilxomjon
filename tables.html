Tables

Show data in rows and columns.

<table / tr / th / td>

Definition

table = the grid, tr = row, th = header cell (bold), td = data cell.

Attributes

AttributeRole
borderBorder width (better to use CSS)
colspanCell stretches over several columns
rowspanCell stretches over several rows

Example (code)

<table>
  <tr><th>Tag</th><th>Role</th></tr>
  <tr><td>p</td><td>Paragraph</td></tr>
  <tr><td>a</td><td>Link</td></tr>
</table>

Example (result)

TagRole
pParagraph
aLink

<caption / thead / tbody>

Definition

caption = table title. thead and tbody separate the header from the body.

Attributes

AttributeRole
(none)Only global attributes

Example (code)

<table>
  <caption>Marks</caption>
  <thead><tr><th>Name</th><th>Mark</th></tr></thead>
  <tbody><tr><td>Sara</td><td>18</td></tr></tbody>
</table>

Example (result)

Marks
NameMark
Sara18

<colspan>

Definition

Merges cells horizontally.

Attributes

AttributeRole
colspanNumber of columns the cell covers

Example (code)

<table>
  <tr><th colspan="2">Team</th></tr>
  <tr><td>Ali</td><td>Sara</td></tr>
</table>

Example (result)

Team
AliSara
