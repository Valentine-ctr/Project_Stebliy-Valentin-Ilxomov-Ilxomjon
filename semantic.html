Semantic & layout

Tags whose names describe their role.

<header / nav / footer>

Definition

header = top of page, nav = menu links, footer = bottom of page.

Attributes

AttributeRole
classCSS class for styling

Example (code)

<header>My site</header>
<nav><a href="#">Home</a> <a href="#">About</a></nav>
<footer>(c) 2026</footer>

Example (result)

Invisible in the page: open the browser tab or press Ctrl+U to see its effect.

<main / section / article>

Definition

main = main content (once per page). section = a theme. article = a self-contained piece.

Attributes

AttributeRole
idUnique name for links
classCSS class

Example (code)

<main>
  <section>
    <article>A blog post</article>
  </section>
</main>

Example (result)

A blog post

<aside>

Definition

Side content related to the main content (ads, notes).

Attributes

AttributeRole
classCSS class for styling

Example (code)

<aside>Did you know? HTML was created in 1991.</aside>

Example (result)

Did you know? HTML was created in 1991.

<div / span>

Definition

div = generic block box, span = generic inline piece. Used to group content for CSS.

Attributes

AttributeRole
classCSS class name
idUnique identifier

Example (code)

<div class="box">A block <span>and an inline part</span></div>

Example (result)

A block and an inline part
