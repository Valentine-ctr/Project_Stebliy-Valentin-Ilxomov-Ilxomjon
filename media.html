Multimedia

Video, audio and embedded pages. Put your own files in the images/ folder.

<video>

Definition

Plays a video file inside the page.

Attributes

AttributeRole
srcPath to the video
controlsShows play/pause buttons
autoplayStarts automatically (usually needs muted)
loopRepeats
posterImage shown before playing
widthWidth in pixels

Example (code)

<video src="Happy_cat.mp4" controls width="320"></video>

Example (result)

<audio>

Definition

Plays a sound file.

Attributes

AttributeRole
srcPath to the audio
controlsShows the player
loopRepeats

Example (code)

<audio src="images/sample.mp3" controls></audio>

Example (result)

<iframe>

Definition

Embeds another web page inside this page.

Attributes

AttributeRole
srcAddress of the page to embed
titleDescription for accessibility
widthWidth in pixels
heightHeight in pixels

Example (code)

<iframe src="index.html" title="Home page" width="300" height="150"></iframe>
