Text formatting

Headings, paragraphs and emphasis.

<h1 – h6>

Definition

Six levels of headings. h1 is the most important, h6 the least.

Attributes

AttributeRole
idUnique name, lets a link jump to this heading
classCSS class for styling

Example (code)

<h1>Main title</h1>
<h2>Subtitle</h2>
<h3>Section</h3>

Example (result)

Main title

Subtitle

Section

<p>

Definition

A paragraph of text. The browser adds space before and after.

Attributes

AttributeRole
classCSS class for styling
titleTooltip shown on hover

Example (code)

<p title="Hello!">This is a paragraph.</p>

Example (result)

This is a paragraph.

<strong / em>

Definition

strong = important text (bold). em = emphasised text (italic).

Attributes

AttributeRole
(none)Only global attributes

Example (code)

<p>This is <strong>very important</strong> and <em>emphasised</em>.</p>

Example (result)

This is very important and emphasised.

<br / hr>

Definition

br breaks the line. hr draws a horizontal line between topics.

Attributes

AttributeRole
(none)Empty tags: no closing tag needed

Example (code)

First line<br>Second line
<hr>
New topic

Example (result)

Second line
New topic

<blockquote>

Definition

A long quotation from another source.

Attributes

AttributeRole
citeURL of the source of the quote

Example (code)

<blockquote cite="https://developer.mozilla.org">
  HTML is the language of the web.
</blockquote>

Example (result)

HTML is the language of the web.
