Forms

Collect information from visitors.

<form>

Definition

Container for form controls; sends the data somewhere.

Attributes

AttributeRole
actionAddress that receives the data
methodget or post

Example (code)

<form action="#" method="post">
  ...
</form>

<input + label>

Definition

input = a field the user fills. label = its caption, linked by for/id.

Attributes

AttributeRole
typetext, email, password, checkbox, radio, number...
nameName of the data sent
idLinks the input to its label
placeholderHint shown inside the empty field
requiredField cannot be empty

Example (code)

<label for="mail">Email</label>
<input type="email" id="mail" name="mail" placeholder="you@example.com" required>

Example (result)

<select / option>

Definition

Drop-down list; each option is one choice.

Attributes

AttributeRole
nameName of the data sent
valueValue sent for an option
selectedOption chosen by default

Example (code)

<select name="lang">
  <option value="html" selected>HTML</option>
  <option value="css">CSS</option>
</select>

Example (result)

<textarea>

Definition

Multi-line text field.

Attributes

AttributeRole
rowsVisible lines
colsVisible width in characters
nameName of the data sent

Example (code)

<textarea name="msg" rows="3" cols="30">Write here...</textarea>

Example (result)

<button>

Definition

A clickable button.

Attributes

AttributeRole
typesubmit sends the form, reset clears it, button does nothing
disabledButton cannot be clicked

Example (code)

<button type="submit">Send</button>
<button type="reset">Clear</button>
