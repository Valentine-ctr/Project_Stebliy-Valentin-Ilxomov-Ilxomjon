<!DOCTYPE / html>

Definition

Tells the browser this is an HTML5 page; <html> is the root element that wraps everything.

Attributes

AttributeRole
langLanguage of the page (helps screen readers and search engines)

Example (code)

<!DOCTYPE html>
<html lang="en">
  ...
</html>

<head>

Definition

Holds information about the page (title, CSS, meta). Nothing inside it is shown on the page.

Attributes

AttributeRole
(none)Uses only global attributes such as id and class

Example (code)

<head>
  <meta charset="UTF-8">
  <title>My page</title>
</head>

<body>

Definition

Contains everything the visitor sees: text, images, links, tables.

Attributes

AttributeRole
classGives a CSS class name to style the body
idUnique identifier

Example (code)

<body>
  <p>Everything visible lives in the body.</p>
</body>

Example (result)

Everything visible lives in the body.
